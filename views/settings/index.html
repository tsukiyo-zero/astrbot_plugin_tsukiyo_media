这个插件怎么跑起来

三个概念：模型 = models.json 里的一条（key + 工作流 + 作者参数）； 工作流 = workflows/ 里的 ComfyUI API 格式 JSON； 后端 = 你在下面填的 ComfyUI 地址。

  1. 在 ComfyUI 里「导出 (API)」得到工作流 json，放进
  2. 在 里加一条模型，workflow 填上面那个文件名
  3. 回本页「模型」表，给它选工作流并勾上启用，然后去 Studio 生成
